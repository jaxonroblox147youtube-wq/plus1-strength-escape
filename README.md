# +1 Strength Escape - Full Game

## How to install

1. Download this repository as ZIP
2. Create the folders and scripts in Roblox Studio exactly as named below
3. Copy the code from each file into the matching script

### File Placement Guide

| File Name | Put it in |
|-----------|-----------|
| `1_ServerScriptService_PlayerStats.luau` | ServerScriptService |
| `2_ServerScriptService_TrainingSystem.luau` | ServerScriptService |
| `3_ServerScriptService_CombatSystem.luau` | ServerScriptService |
| `4_ServerScriptService_RebirthSystem.luau` | ServerScriptService |
| `5_ServerScriptService_ShopSystem.luau` | ServerScriptService |
| `6_ReplicatedStorage_GameConfig.luau` | ReplicatedStorage (ModuleScript) |
| `7_StarterGui_LevelBar.luau` | StarterGui (LocalScript inside a ScreenGui) |
| `8_StarterPlayerScripts_Client.luau` | StarterPlayer > StarterPlayerScripts |

After putting everything in, press Play and test.
